The [`getmnemo`](https://www.npmjs.com/package/getmnemo) package is Mnemo's
official TypeScript and JavaScript SDK. It supports ESM and CommonJS, requires
Node.js 18 or later, and has no runtime dependencies.

## Install

```bash
npm install getmnemo
```

## Create a client

```ts
import { Mnemo } from 'getmnemo'

const mnemo = new Mnemo({
  apiKey: process.env.MNEMO_API_KEY!,
  defaultContainerTag: 'user:jane',
})
```

The API key determines the workspace. Keep full-access keys on your server.

## Add and search

```ts
await mnemo.add({
  content: 'Jane prefers Japanese short-grain rice.',
  memoryType: 'preference',
})

const { results } = await mnemo.search({
  q: 'What rice does Jane prefer?',
  includeSources: true,
})
```

Use a structured scope when it is clearer than a container tag:

```ts
await mnemo.add({
  scope: { type: 'customer', id: 'acme' },
  content: 'Acme renewed through December.',
})
```

Every save, search, document, and video request stays inside the supplied
container.

## Ingest documents

```ts
const accepted = await mnemo.documents.create({
  scope: { type: 'customer', id: 'acme' },
  content: meetingTranscript,
  contentType: 'conversation',
  customId: 'meeting-2026-08-08',
})

const job = await mnemo.jobs.wait(accepted.jobId)
```

`documents.createBatch()` accepts up to 50 documents and reports each failed
item separately.

## Ingest YouTube videos

```ts
const estimate = await mnemo.youtube.estimate({
  url: 'https://www.youtube.com/watch?v=VIDEO_ID',
  mode: 'transcript_and_visuals',
})

if (estimate.quota.willFit) {
  const video = await mnemo.youtube.create({
    scope: { type: 'course', id: 'onboarding' },
    url: estimate.canonicalUrl,
    mode: 'transcript_and_visuals',
  })

  await mnemo.jobs.wait(video.jobId)
}
```

See [YouTube ingestion](/docs/youtube-ingestion) for modes, plan limits, and
evidence behavior.

## Errors and retries

```ts
import { MnemoHTTPError, MnemoTimeoutError } from 'getmnemo'

try {
  await mnemo.jobs.wait(jobId, { timeoutMs: 120_000 })
} catch (error) {
  if (error instanceof MnemoHTTPError) {
    console.error(error.status, error.message)
  }
  if (error instanceof MnemoTimeoutError) {
    console.error('The job is still running')
  }
}
```

The SDK retries rate limits, server errors, and transient network failures with
bounded exponential backoff. Ambiguous memory writes are retried only when all
items have stable idempotency keys.

## Browser usage

Do not embed a full-access API key in a browser bundle. Send requests through
your server or issue a narrowly scoped key for the browser operation.
